# svectorlib

Safe Vector Library (or svectorlib for short) is a C library that intends to help users create and manage elements in vectors safely without worrying to much.
This library was mainly created for learning purposes so it might not be the best to use in production, however feel free to use it or fork it as your own implmentations.
